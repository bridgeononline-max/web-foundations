Styling with CSS

What CSS is

HTML says what is on the page. CSS says how it looks: colours, sizes, spacing, layout.

CSS is a list of rules. Each rule names which elements to style (the selector), then sets one or more property: value; pairs inside curly brackets:

h1 { color: teal; font-size: 40px; }
Try it: change teal to purple. Then add a rule that makes every p grey.

That rule lived in a style tag. There are three places CSS can live.

Three ways to add CSS

Inline: a style attribute on one element. Quick, but only for that element.

Internal: a <style> tag in the head, for this page only.

External: a separate .css file, linked from the head with <link rel="stylesheet" href="site.css">. Every page of a site can link the same file, so one change restyles the whole site. Real sites use this.

Try it: delete the <link> line and watch the font and background go. Put it back.

Next: more ways to pick which elements a rule styles.

What if two of them disagree?
The inline style wins: it is the most specific. Between a style tag and a linked file, the rule that comes later wins. Lesson 4 explains the full order, called specificity.

Element, id and class selectors

An element selector is a tag name: p styles every paragraph.
An id selector starts with #: #title styles the element with id="title".
A class selector starts with a dot: .note styles every element with class="note".

To give several selectors the same style, list them with commas: h1, h2 { … }.

Try it: add class="note" to the plain paragraph. Then add h2 to the first rule: h1, h2 { … }.

Two more selectors: one for everything, and one for attributes.

Universal and attribute selectors

The universal selector * picks every element on the page. It's often used to reset spacing, like * { margin: 0; }.

An attribute selector uses square brackets. [title] picks elements that have a title attribute. [type="email"] picks elements whose type is exactly "email".

Try it: change [type="email"] to [type="password"]. Then delete the * rule.

Now, colours beyond their names.

Colours

Three properties take a colour: color (text), background-color and border-color.

Besides names like teal, you can mix any colour from red, green and blue light, each from 0 (none) to 255 (full): rgb(255, 99, 71) is lots of red, some green, a little blue: tomato.

A hex code writes the same three amounts in base 16: #ff6347 is ff red (255), 63 green (99), 47 blue (71).

Try it: set the first box to rgb(0, 0, 255), then rgb(255, 255, 0). Which colour does full red plus full green make?

Colours look good on borders too.

How do I find a colour's code?
Search "colour picker" online, or use your browser's developer tools. In the editor, <input type="color"> also shows a picker with its hex code.

Borders

A border needs a width, a style and a colour, written together: border: 3px solid teal;

Styles include solid, dashed, dotted and double. One side only: border-bottom, border-left and so on.

border-radius rounds the corners. On a square, 50% makes a circle.

Try it: make the second box's border dotted. Then change the third box's radius to 10px.

Notice the space between each border and its words? That space has a name.

Padding and margin

Padding is the space inside the border, between the border and the content. Margin is the space outside the border, pushing other elements away.

One value sets all four sides: padding: 20px. Two values: top and bottom, then left and right: padding: 10px 30px. Four go clockwise from the top: margin: 10px 0 20px 0.

Try it: set the box's padding to 40px, then its margin to 40px. Watch which one moves the border.

Content, padding, border, margin: together they decide how much room a box takes.

How do I centre a box?
Give it a width and margin: 0 auto;. auto shares the leftover space equally on the left and right.

The box model

Every element is a box made of four layers: the content, then padding, then border, then margin. This is the box model.

So far boxes sit where they fall. CSS can also move them.

position: static and relative

The position property decides how a box is placed. The default is static: the box sits wherever it falls on the page, and top, left and the like do nothing.

position: relative lets you nudge a box away from where it would have been. top: 20px pushes it 20px down from its usual spot; left: 30px pushes it right. The space it came from stays empty.

Try it: change left: 30px to left: 80px. Then change relative to static.

Relative boxes keep their space. Absolute ones don't.

position: absolute

position: absolute lifts a box out of the page's flow: the other elements close the gap as if it weren't there.

Its top, right, bottom and left are measured from the nearest parent that has a position other than static. The usual trick: give the parent position: relative, so the child is placed inside it.

Try it: change top: 10px; right: 10px; to bottom: 10px; left: 10px;. Then delete position: relative from .card.

Two more: boxes that stay put while the page scrolls.

fixed and sticky

position: fixed pins a box to the screen: it stays in the same spot while the page scrolls. Chat buttons in a corner use this.

position: sticky scrolls normally until it reaches its top value, then sticks there. Menus that stay at the top use this.

Try it: scroll inside the page on the right. Watch the menu stick and the button stay in its corner.
