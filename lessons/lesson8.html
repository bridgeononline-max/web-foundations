Bootstrap and your portfolio

What Bootstrap is

Bootstrap is a free CSS file full of ready-made classes. Instead of writing CSS, you add class names: class="btn btn-primary" makes a styled blue button.

Add it with one <link> in the head, pointing to a copy online (a CDN). Every editor in this lesson starts with that line.

Try it: delete the <link> line and see the plain page. Put it back. Then change btn-primary to btn-success.

Let's tour the most useful classes, starting with colour.

Which version is this?
Bootstrap 5.3. The number in the link chooses the version. The class names here are the same in all of Bootstrap 5.

Colours and backgrounds

Bootstrap names its colours by job: primary (blue), secondary (grey), success (green), danger (red), warning (yellow), info, light and dark.

text-danger colours the text. bg-success colours the background. text-white makes text white, for dark backgrounds.

Try it: make the last box bg-warning. Then make the first paragraph text-success.

Did you spot p-2 and mb-2? Those are spacing classes.

Spacing

Spacing classes are short: what, which side, then a size from 0 to 5.

m margin, p padding · then t top, b bottom, s start (left), e end (right), x left and right, y top and bottom, or nothing for all sides · then the size.

So mt-3 is margin-top size 3, and px-4 is padding on the left and right, size 4. mx-auto centres a box that has a width.

Try it: change the box's p-1 to p-5. Then add mt-4 to the second box.

Next: borders, shadows and placing things.

How big is each size?
0 = none, 1 = a quarter of the text size, 2 = half, 3 = one text size (16px), 4 = one and a half, 5 = three. w-50 means width 50%; there are also w-25, w-75 and w-100.

Borders, shadows and position

border adds a thin border; border-primary colours it. rounded rounds the corners, rounded-circle makes a circle, and shadow adds a soft shadow.

Position classes match CSS: position-relative on the parent, position-absolute top-0 end-0 on the child puts it in the top-right corner.

Try it: move the badge to the bottom-left with bottom-0 start-0. Then add shadow to the picture.

Next: text styles, and buttons.

Text and buttons

Text: text-center (also text-start, text-end) · fw-bold bold · fst-italic italic · fs-1 (biggest) to fs-6 (smallest) · text-uppercase.

Buttons: btn plus a colour, like btn btn-danger. btn-outline-primary gives an outline only. btn-lg and btn-sm change the size. A link with these classes looks like a button too.

Try it: make the heading fs-1. Then change the second button to btn-outline-dark btn-lg.

Bootstrap does Flexbox with classes too.

Flex classes

d-flex means display: flex. Then the same ideas as CSS, as classes: justify-content-between, justify-content-center, align-items-center, flex-column, and gap-2 for space between items.

d-none hides an element, like display: none.

Try it: change justify-content-between to justify-content-center. Then add gap-3 to the row of buttons.

Next: Bootstrap's grid, for layouts that fit every screen.

The grid: container, row, col

Bootstrap's grid has three layers. A container centres the content and keeps it from getting too wide. Inside it, a row holds columns. Inside the row, each col is a column.

Every row is 12 units wide. col on its own shares the width equally. col-4 takes 4 of the 12 units: one third. col-8 takes two thirds. In one row, the numbers should add up to 12.

Try it: change the second row to col-3 and col-9. Then add a third col to the first row.

The real power: different widths on different screens.

Breakpoints

A breakpoint is a screen width where the layout changes. Bootstrap's are sm (576px), md (768px), lg (992px) and xl (1200px).

col-md-4 means: from md (768px) and wider, take 4 units; narrower than that, take the full width. So col-12 col-md-4 gives three columns on a laptop and one column on a phone, with no media queries to write.

Try it: drag the screen width below 768px and watch the columns stack. Then change col-md-4 to col-sm-4 and find the new breakpoint.

Plan your portfolio

A portfolio is a personal website that shows who you are and what you've built. It's often the first thing an employer looks at. Yours will have five sections, one under the other, with a menu at the top that jumps to each:

MainYour photo, your name, one line about you.
AboutA short paragraph: who you are and what you're learning.
SkillsHTML, CSS, JavaScript, Bootstrap…
ProjectsCards for the things you built, with links.
ContactA form that emails you, plus your links.

Each section is a <section> with an id, so menu links like href="#about" jump to it.

Start at the top: the menu and the main section.

Can I start from a template?
Yes. Sites like BootstrapMade, Start Bootstrap and ThemeWagon have free portfolio templates. Look at a few for ideas, but build your own first, so you understand every line.

The menu and main section

Bootstrap's navbar classes make a menu bar. sticky-top keeps it at the top as you scroll. navbar-expand keeps the links in one row.

The main section is often called the hero: a big, centred area with your photo and name. min-vh-100 would make it fill the whole screen; here it's shorter so it fits the preview.

Try it: put your own name in. Click "About" in the menu to jump. Change the hero's bg-light to bg-dark text-white.

Next: the sections in the middle.

About, skills and projects

About: two or three honest sentences, in your own voice.

Skills: Bootstrap badges make neat little labels.

Projects: Bootstrap's card classes (card, card-body, card-title, card-text) in a responsive grid. Link each card to the project's live page or code on GitHub.

Try it: add your own skills as badges. Add a third project card in the row.

Last section: a contact form that really sends you an email.

A contact form with EmailJS

A web page can't send email by itself. EmailJS is a free service that does it for you: your form sends its fields to EmailJS, and EmailJS emails them to you. Setting it up:

  1. Sign up at emailjs.com and connect your email (e.g. Gmail): that gives a Service ID.
  2. Create an email template using {{name}}, {{email}} and {{message}}: that gives a Template ID.
  3. Copy your Public Key from the Account page.
  4. Add the code below to your page, with your own three values. The form fields' names must match the template.
<form id="contact-form">
  <input name="name" class="form-control mb-2" placeholder="Name" required>
  <input name="email" type="email" class="form-control mb-2" placeholder="Email" required>
  <textarea name="message" class="form-control mb-2" rows="4" required></textarea>
  <button class="btn btn-primary">Send</button>
</form>

<script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@4/dist/email.min.js"></script>
<script>
  emailjs.init({ publicKey: "YOUR_PUBLIC_KEY" });
  document.getElementById("contact-form").addEventListener("submit", function (event) {
    event.preventDefault();
    emailjs.sendForm("YOUR_SERVICE_ID", "YOUR_TEMPLATE_ID", this)
      .then(() => alert("Message sent!"), () => alert("Sorry, it didn't send."));
  });
</script>

event.preventDefault() stops the form from reloading the page, so the JavaScript can send it instead. .then(…) runs one function when sending works and the other when it fails. This can't run here; try it in your own site.

Your site is ready. Now put it online.

Put it online with GitHub Pages

GitHub stores code online. GitHub Pages turns a folder of HTML, CSS and JS into a free website. Your main page must be named index.html.

  1. Make a free account at github.com.
  2. Click + → New repository. Name it, for example, portfolio. Choose Public, then Create repository.
  3. Click uploading an existing file, drag in index.html and your other files (pictures, CSS), then Commit changes.
  4. Open Settings → Pages. Under "Branch", pick main and / (root), then Save.
  5. After a minute or two your site is live at https://YOUR-USERNAME.github.io/portfolio/.

To update the site later, upload the changed files again: it refreshes by itself.

Last step: profiles that point people to your site.

Can my address be shorter?
Yes: name the repository exactly YOUR-USERNAME.github.io. Then the site lives at https://YOUR-USERNAME.github.io/ with nothing after it.

Your GitHub and LinkedIn profiles

GitHub:

  • A clear photo and a one-line bio.
  • Pin your best repositories (portfolio, to-do app…) to the top of your profile.
  • Optional: a profile README, a repository named exactly like your username, whose README shows on your profile.

LinkedIn:

  • A photo, and a headline such as "Frontend developer · HTML, CSS, JavaScript".
  • An About section in your own words, and your skills.
  • Your portfolio link in your contact info, and projects in the Featured section.

Link all three together: your portfolio links to GitHub and LinkedIn, and both link back to your portfolio.
