Your first web page

What is a web page?

Every web page is a plain text file. Your browser reads the file and draws the page it describes.

The file marks each piece of text with a short label in angle brackets, such as <h1> for "a big heading" or <p> for "a paragraph". The language of these labels is called HTML.

Try it: change the words on the left. The page on the right changes as you type.

Those labels have a name and a shape. Let's look closer.

What a tag does

A label like <p> or <h1> is called a tag. The tag tells the browser what a piece of content is, and so how to show it.

The same word looks different in different tags: <h1>Hello</h1> shows as a big heading, <p>Hello</p> as ordinary text.

Two kinds of tags

Container tags come in pairs: an opening tag, and a closing tag with a / before the name. The content goes between them.

<p>Hello!</p>

Self-closing tags hold no content, so there is nothing to close: just one tag. <br> starts a new line, <hr> draws a line across, <img> shows a picture.

A tag together with its content makes one element.

Try it: delete the closing </b> and watch the rest of the text. Then add a second <hr>.

Without its closing tag, the browser guesses where bold stops, and it guesses "much later". Always close a container tag.

I've seen <br /> with a slash. Is that different?
No, it's the same tag. In HTML the slash is optional. Self-closing tags are also called empty or void elements.

Every page's skeleton

A full HTML file wraps your content in the same frame every time. Elements sit inside other elements, like boxes inside boxes. We indent the inner ones so the boxes are easy to see.

<head> holds facts about the page that are not shown on it, such as the <title>: the name on the browser tab.

<body> holds everything the reader sees.

Try it: change the words inside <title>. Watch the tab above the page.

Inside the body, the first thing most pages need is a heading.

What is <!DOCTYPE html> for?
It tells the browser "this is a modern HTML page". It always goes on the very first line, and it has no closing tag.

Headings

Headings are titles for the parts of a page. There are six sizes: <h1> is the biggest and most important, <h6> the smallest.

Use one <h1> for the page's main title, <h2> for its sections, <h3> for parts inside a section, and so on.

Try it: turn the <h2> into an <h5>. Change both its tags.

Under a heading comes ordinary text: paragraphs.

Can I pick <h3> just because I like its size?
Better not. Search engines and screen readers use headings to understand how the page is organised. To change the size of text, use CSS (coming in Lesson 3).

Paragraphs and line breaks

<p> makes a paragraph: a block of text with a gap above and below it.

The browser ignores extra spaces and new lines in your file. Ten spaces show as one, and pressing Enter does not start a new line on the page.

To start a new line inside a paragraph, use <br> (line break), a self-closing tag.

Try it: compare the first two paragraphs. Then add a <br> to the third, after "Day 1".

Time to put these together.

How do I get a bigger gap, then?
With CSS, using margin and padding (coming in Lesson 3). Don't stack many <br> tags to make space.

Next: tags that need a few extra details.

Attributes: extra details for a tag

Some tags need extra details. You write them inside the opening tag, as name="value". These details are called attributes.

<p title="A hint">Hover me</p>

An attribute is a name, an = sign and a value in quotes. One tag can have several, with spaces between them.

Try it: hover over each paragraph on the right (or press and hold on a phone). Then change the words in title.

The most useful attribute of all makes links.

Links

The <a> tag makes a link. Its href attribute holds the address to go to:
<a href="address">words to click</a>

Add target="_blank" to open the link in a new tab.

Try it: click a link on the right. Then change its words or its address.

Links take you to things. Next, pictures.

What else can href point to?
Another page of your own site, like href="about.html".
An email address: href="mailto:you@example.com" opens the reader's email app.

Images

<img> shows a picture. It is a self-closing tag. It needs two attributes:

src: where the picture file is.
alt: words that describe it. Screen readers read them aloud, and they show if the picture can't load.

width sets the width in pixels; the height follows to keep its shape.

Try it: change the width to 120. Then break the src (type notebookX.svg) and see the alt words appear.

Now, how to change the way any element looks.

Where does a picture's address come from?
Put the picture file in the same folder as your HTML file and write its name: src="photo.jpg".
Or use the full web address of a picture online, starting with https://.

The style attribute

The style attribute changes how one element looks. Its value is a list of property: value; pairs:
style="color: teal; font-size: 24px;"

Four to start with: color (text colour), background-color, font-size, and text-align (left, center or right).

This is a first taste of CSS, the styling language. Lesson 3 covers it properly.

Try it: change tomato to teal, and 20px to 32px.

Practice time: links, pictures and style together.

Which colour names can I use?
About 140 names work, such as red, teal, tomato or gold. You can also use colour codes like #ff6347 (explained in Lesson 3).

Next: small tags that change words inside a paragraph.

Formatting text

A few small tags change how words look inside a paragraph: bold, italic, highlighted, struck out, and raised or lowered like in H₂O and x². Each one is shown on the right.

Try it: add a new paragraph that says E = mc², using <sup> for the 2.

Next: lists, for items that belong together.

What's the difference between <b> and <strong>?
They look the same. <strong> also means "this is important", so screen readers stress it. In the same way, <em> means "say this with emphasis", while <i> is only italic.

Lists

<ul> makes an unordered list, with bullets. <ol> makes an ordered list, with numbers. Inside both, each item is an <li> (list item).

A description list, <dl>, pairs each term (<dt>) with its description (<dd>), like a glossary.

Try it: add an item to each list. Then change <ol> to <ol type="A">.

Can a list hold another list? Yes.

Can the numbers start at 5, or be letters?
Yes. <ol start="5"> starts counting at 5.
<ol type="A"> uses A, B, C, and type="i" uses i, ii, iii.

Lists inside lists

A list item can hold a whole new list. Put the inner <ul> or <ol> inside the <li>, just before its </li>. This makes a multi-level list, like the outline of a book.

Each level gets a different bullet by itself: ● then ○ then ■.

Try it: add a third level under CSS, with two items: Flexbox and Grid.

One last practice before the test.

Why must the inner list go inside the <li>?
Only <li> elements may sit directly inside <ul> or <ol>. The inner list belongs to one item, so it goes inside that item.
