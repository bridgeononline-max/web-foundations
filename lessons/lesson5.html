JavaScript basics

What JavaScript is

HTML is what's on the page, CSS is how it looks. JavaScript is what it does: react to clicks, check a form, work things out, change the page.

JavaScript is a list of instructions the browser runs from top to bottom. console.log(…) writes something to the console: a box developers use to see what their code is doing.

Try it: change the words in quotes, then press ▶ Run. Add a third line that logs 2 + 2 (no quotes).

A line starting with // is a comment: a note for people. JavaScript skips it.

Programs need to remember things. That's what variables are for.

Where is the console in a real browser?
Press F12 (or right-click → Inspect) and open the Console tab. Every console.log from the page shows up there.

Variables: let and const

A variable is a named box that holds a value. let makes a box whose value can change later. const makes one that can't.

let score = 10;

Here the box is named score and holds 10. Later, score = 15; puts 15 in it instead. Doing that to a const gives an error.

Try it: run it. Then add city = "Delhi"; at the end and run again. Read the error.

console.log is one way to show a value. There are three more.

What about var?
The old way to make a variable, like let but with confusing rules about where it can be seen. You'll meet it in older code; use let and const in yours.

Four ways to show output

console.log(): writes to the console, for you, the developer.
document.write(): writes straight onto the page.
alert(): pops up a message box that the visitor must close.
prompt(): pops up a box that asks a question; whatever the visitor types comes back as a value.

Try it: press ▶ Run, answer the question, and close the alert. See where each output went.

Values come in different kinds, called types.

Should I use document.write in real sites?
No: if it runs after the page has loaded, it wipes the whole page. It's fine for practice. Lesson 7 shows the proper way to change a page.

Data types

Every value has a type. The five basic ones are called primitive types:

42, 3.5: a number · "hello": a string (text, in quotes) · true / false: a boolean · null: "empty on purpose" · undefined: "no value given yet".

typeof tells you a value's type: typeof 42 gives "number".

Try it: run it. Then change age to "20" (with quotes) and run again: what type is it now?

Primitives hold one value. Two other types hold many.

Are there only five?
Two more exist: Symbol (a unique label) and BigInt (whole numbers too big for a normal number, written like 123n). You'll rarely need them.

Arrays and objects

An array is a list in square brackets: ["red", "green", "blue"]. Each item has a position number called its index, starting at 0. colors[0] is "red", and colors.length is how many items there are: 3.

An object groups named values in curly brackets. Each name with its value is a key-value pair: { name: "Asha", age: 20 }. person.name reads one value.

These are non-primitive types: they hold many values.

Try it: log colors[2]. Then add city: "Kochi" to the object (after a comma) and log person.city.

Last building block: a way to name a piece of work and reuse it.

Functions

A function is a named piece of code you can run whenever you like, by calling it: its name followed by brackets.

The names in the brackets of the definition are parameters: empty boxes. The values you pass when calling are arguments: they fill the boxes. return sends a value back to whoever called.

function add(a, b) { return a + b; }

add(2, 3) fills a with 2 and b with 3, and gives back 5.

Try it: call add(10, 20) in a new console.log. Then write a function double(n) that returns n * 2.

Next: doing maths and comparing values.

Arithmetic and assignment

Maths operators: + - * (times) / (divide) ** (power: 2 ** 3 is 8) and %, the remainder: 17 % 5 is 2, because 17 = 3 × 5 + 2.

= puts a value in a variable. Shortcuts change it in place: x += 5 means x = x + 5; x++ adds 1.

Try it: predict each line before you run. Then log 20 % 6.

Next: questions with a yes-or-no answer.

What is % useful for?
Checking if a number is even: n % 2 is 0 for even numbers, 1 for odd ones. Or doing something every 3rd time: i % 3 === 0.

Comparison and logic

Comparisons give true or false: > < >= <=, and === (equal) and !== (not equal).

== is a looser "equal" that converts types first, so 5 == "5" is true. === checks the type too: 5 === "5" is false. Use ===.

Logical operators join answers: && (and: both true), || (or: at least one true), ! (not: flips it).

Try it: predict, then run. Change age to 15 and run again.

That loose == converted "5" into 5. JavaScript converts types a lot.

Type conversion

When types are mixed, JavaScript converts one of them by itself. This is called coercion.

+ with a string joins text: "5" + 1 gives "51". Other maths turns the string into a number: "5" - 1 gives 4.

To convert on purpose: Number("42") gives 42, String(42) gives "42", and Number("hi") gives NaN, "not a number".

Try it: predict each line, then run. Fix the last line so it logs 30, not "1020".

Practice: a shop bill.

Why does this matter?
prompt() and form boxes always give back strings. If a visitor types 10, you get "10". Add two of them and you'd get "1010": use Number() first.

Now, making decisions.

if and else

if runs a block of code only when a condition is true. else runs when it's false. else if checks another condition in between. JavaScript checks them top to bottom and runs only the first one that's true.

if (marks >= 50) { … } else { … }
Try it: run with marks 72. Then try 95, 40 and 50. Which line prints for each?

When you compare one value against many fixed choices, there's a tidier way.

switch

switch compares one value against a list of cases, using ===. It runs the matching case, and break stops it there. default runs when nothing matches.

Try it: change day to 6, then 9. Then add a case for 3: "Wednesday".

And for a quick either-or, there's a one-liner.

What if I forget break?
It keeps going and runs the next case's code too, until it finds a break. That's why cases 6 and 7 can share one block.

The ternary operator

The ternary operator picks one of two values in a single line:
condition ? valueIfTrue : valueIfFalse

age >= 18 ? "adult" : "minor" gives "adult" when age is 20, and "minor" when it's 15. Use it for short choices; use if/else when there's more to do.

Try it: change age and run. Then write a ternary that logs "even" or "odd" for n, using n % 2.
