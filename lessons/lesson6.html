Loops, functions and strings

The for loop

A loop runs the same code again and again. A for loop has three parts in its brackets, separated by semicolons:

▶ Watch first: 34 seconds, in Malayalam
Narrated with an AI copy of your teacher's voice, used with his permission.
for (let i = 1; i <= 5; i++) { … }

Read it as: start i at 1; while i is 5 or less, run the block; after each round, add 1. So the block runs with i = 1, 2, 3, 4, 5, then stops when i becomes 6.

Try it: make it count to 10. Then make it count by twos: change i++ to i += 2.

for is best when you know how many rounds. When you don't, use while.

while and do…while

while (condition) { … } checks the condition first, and repeats the block as long as it's true. If it's false from the start, the block never runs.

do { … } while (condition); runs the block first, then checks. So it always runs at least once.

Something inside must change the condition, or the loop never ends and the page freezes.

Try it: set n to 0 in both loops and run. Which loop still prints once?

More about functions

A function can also be stored in a variable. This is a function expression: const square = function (n) { return n * n; };

An arrow function is a shorter way to write the same: const square = (n) => n * n;. With one line after the arrow, its value is returned without writing return.

A parameter can have a default value, used when no argument is given: function greet(name = "friend").

Try it: call greet() with nothing, then greet("Ravi"). Then write an arrow function half that returns n / 2.

Functions can live inside objects too.

Objects in depth

Read a value with a dot, car.brand, or with square brackets and a string, car["brand"]. Brackets also work when the key is in a variable.

Change or add a value the same way: car.color = "red";.

A function stored in an object is a method. Inside it, this means "the object this method belongs to".

Try it: add car.year = 2024; before the last line and run. Then call car.describe() again after changing the colour.

How do you go through every key of an object, or every item of an array?

for…in and for…of

for (let key in object) goes through an object's keys, one per round. Use object[key] to get each value.

for (let item of array) goes through an array's items, one per round. It also works on a string, one letter at a time.

Try it: add a key email to user and run. Then loop over the string "hi!" with for…of.

Practice: functions and objects together.

How do I remember which is which?
in for keys in an object; of for each item of a list. for…in on an array gives the indexes ("0", "1", "2"), not the items.

Now, working with text.

Strings: the basics

A string is a row of characters, each with an index starting at 0, just like an array. .length is how many characters it has.

Strings come with built-in functions called methods, written after a dot: charAt(0) the first character · toUpperCase() · toLowerCase() · trim() removes spaces at both ends · concat() joins strings.

Try it: log word.charAt(3). Then log the length of messy before and after trim().

Next: cutting strings into pieces.

Does toUpperCase() change the original string?
No. String methods give back a new string; the original stays the same. To keep the result, store it: let big = word.toUpperCase();

Cutting and changing strings

slice(start, end) cuts from index start up to, but not including, end. "JavaScript".slice(0, 4) is "Java". A negative number counts from the end: slice(-6) is "Script".

split(",") cuts a string into an array at each comma · replace("a", "b") swaps the first "a" for "b" · padStart(5, "0") adds zeros at the front until it's 5 long; padEnd adds at the end.

Try it: log lang.slice(4). Then split date at the "-" marks.

Next: finding things inside a string.

What are substring and substr?
substring(start, end) is like slice, but doesn't take negative numbers. substr(start, length) takes a length instead of an end; it's old, so prefer slice.

Searching in strings

indexOf("x") gives the index of the first "x", or −1 if there isn't one. lastIndexOf finds the last. search() works like indexOf, and can also take a pattern.

Three give true or false: includes("x") · startsWith("x") · endsWith("x").

match(/a/g) finds every match, using a pattern, and gives them back as an array.

Try it: check whether email ends with ".com". Then find where "@" is.

Joining strings with + gets messy. There's a cleaner way.

Template literals

A template literal is a string written between backticks `…` instead of quotes. Inside it, ${…} drops in the value of any variable or expression.

"Hi " + name + ", you are " + age becomes `Hi ${name}, you are ${age}`. Template literals can also span several lines.

Try it: change qty and run. Then rewrite the last line as a template literal.
