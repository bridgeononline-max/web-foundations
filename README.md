# Web Foundations

An interactive notebook for learning HTML, CSS and JavaScript by writing them, then building a portfolio site.
Built on [study-notebook-design](https://github.com/mo-ri-ch/study-notebook-design).

Open it at https://gradlabs.in/learn/web-foundations/ (unlisted: shared by link only).

## Lessons

1. Your first web page: tags, headings, paragraphs, links, images, formatting, lists ✅
2. Tables, forms and boxes (soon)
3. Styling with CSS (soon)
4. Layout: Flexbox and Grid (soon)
5. JavaScript basics (soon)
6. Loops, functions and strings (soon)
7. Arrays and the DOM (soon)
8. Bootstrap and your portfolio (soon)

## What's here

```
index.html          home page: a live editor and the path of lessons
lessons/            one page per lesson
assets/course.js    the lesson list and settings
assets/live.js      live HTML editors and self-ticking challenges (this course only)
assets/img/         pictures the editors can use (src="notebook.svg")
```
