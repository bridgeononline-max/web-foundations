# Web Foundations

An interactive notebook for learning HTML, CSS and JavaScript by writing them, then building a portfolio site.
Built on [study-notebook-design](https://github.com/mo-ri-ch/study-notebook-design).

Open it at https://gradlabs.in/learn/web-foundations/ (unlisted: shared by link only).

## Lessons

1. Your first web page: tags, headings, paragraphs, links, images, formatting, lists
2. Tables, forms and boxes: tables, forms, div, id and class, the style tag, semantic elements, video, audio, meta tags
3. Styling with CSS: three ways to add CSS, selectors, colours, borders, padding, margin, the box model, position
4. Layout: display, Flexbox, pseudo-classes, combinators, specificity, Grid, transitions, animation, media queries
5. JavaScript basics: variables, output, data types, arrays, objects, functions, operators, conversion, if / switch / ternary
6. Loops, functions and strings: for, while, arrow functions, objects, for…in / for…of, string methods, template literals
7. Arrays and the DOM: array methods, searching, sorting, finding and changing elements, events, creating elements
8. Bootstrap and your portfolio: utilities, the grid, breakpoints, a five-section portfolio, EmailJS, GitHub Pages

Every lesson has live editors on each page, self-ticking practice pages and a test.

## What's here

```
index.html          home page: a live editor and the path of lessons
lessons/            one page per lesson
assets/course.js    the lesson list and settings
assets/live.js      live HTML and JavaScript editors, consoles and self-ticking challenges (this course only)
assets/lesson.css   small styles shared by the lessons
assets/img/         files the editors can use: notebook.svg, clip.mp4, chime.mp3, site.css
```
